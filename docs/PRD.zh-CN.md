# 拾文 · 产品需求文档

[English](PRD.en.md)

版本：v0.2，2026-09-17。此次产品修正优先于此前“手动选择文档目录”的方案。

## 1. 产品目标

提供类似 Everything 的使用流程：**打开应用 → 自动发现本机文件 → 直接输入搜索 → 打开结果**。用户无需选择文件夹，不需要整理成“只有文档”的目录。在文件名搜索之上，提供离线 PDF、Markdown、DOCX 全文检索和上下文预览。

“类似 Everything”指使用流程和文件搜索能力，不代表已经采用 NTFS MFT / USN 或达到相同速度。不以“竞品不能检索正文”作为产品前提。

## 2. 默认行为

- 正常启动立即自动发现本地磁盘，已有索引可直接查询。
- 各类常规文件及文件夹按名称建立索引，不限制为文档格式。
- PDF、Markdown、DOCX 正文通过独立后台任务逐步提取；慢文件不能阻塞名称发现。
- 搜索、预览、索引全部本地离线，无账号、无遥测、无文件上传。
- 默认不移动、改写、重命名或删除任何原文件。

## 3. 扫描范围

Windows 发现带盘符的固定磁盘；Linux / macOS 从本地目录树扫描，并优先发现用户主目录。遵守当前系统账户与 macOS 隐私权限，不申请管理员权限。

默认跳过虚拟系统文件系统、网络挂载、符号链接、常见缓存 / 依赖 / 回收站目录和自身索引目录。普通隐藏文件可以按名称查找。云端占位文件不主动下载。可选的“索引与排除”用于排除子目录；无需先配置包含范围。

保留旧版的排除规则和收藏。重叠范围不得产生重复结果。清除数据后暂停自动索引；继续时从自动磁盘重建，原文件不变。

## 4. 搜索与交互

- 提供“文件名 + 内容”“仅文件名”“仅文档内容”三种方式。
- 文件名允许单字符；正文每个词至少两个字符。单字符条件只匹配名称。
- 支持中文连续片段、英文大小写归一化、全角归一化、双引号短语和空格分隔 AND 条件。
- 文件类型（含文件夹）、磁盘范围和收藏可组合；提供相关度 / 修改时间排序。
- 结果显示名称、类型、路径及真实命中片段。正文不可解析时仍保留名称索引并显示原因。
- 单击查看提取文字，双击 / Enter / 打开原文件调用系统应用；文件夹直接打开。
- 保留中英文界面、浅色 / 深色 / 跟随系统、可关闭的玻璃效果及键盘导航。
- 首屏和自动模式管理界面不出现必须完成的文件夹选择流程。

## 5. 索引生命周期

名称发现分批提交 SQLite，避免先把整盘清单装入内存。正文独立串行解析，单文档独立进程、60 秒超时。持久化 pending 状态可在暂停 / 重启后继续。

新增、改动、消失文件通过周期核对更新；一次遍历未完成或被暂停，不得把未访问到的旧文件误判为删除。改动正文先撤下旧文本，完成新解析后再呈现。单文件重试保留收藏，排除规则立即影响查询。

beta.4 使用普通文件遍历和约 30 秒间隔核对（另加扫描时间），不为全盘目录创建递归监听器。MFT / USN、增量事件日志和更大文件库的性能优化留待后续。

## 6. 文档与隐私边界

只解析 PDF、UTF-8 Markdown、DOCX 正文及普通表格。默认解析限制：单文件 100 MiB、PDF 1,000 页、提取文本 10 MiB。不含 OCR、AI、原排版渲染、数据库自动修复和重命名收藏迁移。

索引包含路径及提取正文，未做应用级加密。依赖系统账户权限和磁盘加密保护。问题反馈只提交合成样例，不上传私人文件或索引。

## 7. 验收

1. 新安装无需选文件夹即可显示发现进度和本机文件。
2. 同一混合目录中的图片、压缩包、代码、文档、子目录都能按名称查询；PDF / Markdown / DOCX 还能检索正文。
3. 暂停、重启、删除 / 更新、排除 / 撤销排除行为可验证，且不改动原文件。
4. 名称先可用，慢解析不会阻塞名称发现；名称项不被当成解析错误。
5. Windows、macOS、Linux 构建和原生桥接自检通过，提供公开 Release、校验和及双语文档。
6. 检查旧索引升级与排除规则保留，普通隐藏文件和不可访问位置的行为有明确说明。

## 8. 性能验收仍需补充

全盘文件名检索的首建时间、百万级条目内存 / 延迟、实时更新和完整 GUI 内存需要单独测量。原定文档基准的 4 核 / 8 GB、40% PDF / 40% Markdown / 20% DOCX、至少 100 条查询以及冷热缓存跨平台测试仍未完成。

[beta.3 合成基准](PERFORMANCE.zh-CN.md)只衡量指定文档语料，不应作为 beta.4 全盘索引性能承诺。
