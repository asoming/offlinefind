# 使用说明

[English](USER_GUIDE.en.md) · [返回首页](../README.zh-CN.md)

## Linux 安装

支持 Ubuntu 22.04 / 24.04 x64 桌面。下载 `.deb` 后用系统软件安装器打开，或执行：

```bash
sudo apt install ./Shiwen-*-linux-amd64.deb
shiwen
```

安装后可在应用菜单找到“拾文”。免安装版解压 tar.gz，进入 Shiwen 文件夹运行 `./shiwen`。它依赖系统 Python 3.10+、GTK 3 与 WebKit；若缺少依赖，先执行：

```bash
sudo apt install python3 python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-webkit2-4.1 xdg-utils
```

Ubuntu 22.04 已有 `gir1.2-webkit2-4.0` 时也可以使用。Python 应用依赖随包提供，无需 pip 或虚拟环境。系统依赖需提前准备好；之后运行、索引和搜索均可离线。其他 Linux 发行版、ARM64 与无桌面环境暂未验证。`sudo apt remove shiwen` 卸载程序，但保留索引与原文件；删除索引请使用应用设置。

## 打开即搜

正常打开拾文即可自动扫描本地磁盘，不需要选择文件夹，也不要求文件夹只包含文档。先收录所有常规文件和文件夹的名称；PDF、Markdown、DOCX 的正文由独立后台任务提取。图片、视频、压缩包、代码等其他文件只建立名称索引，不读取其正文。

Windows 自动发现盘符式固定磁盘；Linux / macOS 从本地目录树扫描并优先处理用户主目录。跳过虚拟系统目录、网络挂载、`.git`、`.cache`、依赖目录、回收站、符号链接以及自己的索引目录。普通隐藏文件可按名称搜索。没有读取权限的目录会跳过；不要求管理员权限，也不会主动下载云端占位文件。macOS 受系统隐私权限控制，未获权限的位置不能检索。

侧栏“索引与排除”用于可选的排除设置。正常使用没有添加目录这一步；旧版本的目录和排除规则会保留，重复范围不会造成重复结果。

自动发现与正文解析独立运行，慢速 PDF 不会阻塞文件名入库。点击索引状态可以暂停 / 继续；暂停会同时停止新文件发现和后续正文任务。变化通过约 30 秒间隔的磁盘核对发现，实际延迟还包括目录扫描耗时。当前使用普通文件遍历，尚未实现 Everything 的 NTFS MFT / USN 加速，不承诺同等首建速度或即时更新。

## 搜索规则

| 输入 | 含义 |
| --- | --- |
| `部署` | 在名称或正文中查找这个双字片段 |
| `预算 审批` | 同一份文档同时包含两个条件 |
| `"offline deployment"` | 连续短语，忽略英文大小写和连续空白差异 |
| `C++` | 作为普通文字匹配，不执行正则表达式 |

文件名允许单个规范化字符；单字符条件仅匹配名称。“仅文档内容”要求每个词至少两个字符。最多 12 个词、总计 256 个输入字符。英文大小写、全角兼容字符会规范化。当前不做简繁转换、OCR、拼写纠正、同义词和语义搜索。

搜索框下可选“文件名 + 内容”“仅文件名”“仅文档内容”。类型按钮（含文件夹）、磁盘与收藏范围可以组合。“最近修改”使用原文件的修改时间。清空关键词后，显示当前范围内最近修改的文档，已有筛选继续生效。

每次最多显示 50 项，可点击“加载更多”。未检查全部候选前，不显示伪造的精确总数。

## 预览和打开

单击结果查看提取文本，通过上下箭头切换命中的页或文本块。位置对应 PDF 物理页、Markdown 源文件起始行、DOCX 段落序号。此版本不渲染原始 PDF 页面，也不还原 Word 排版。

“打开原文件”、双击结果或在结果列表按 Enter，均调用系统默认应用。“在文件夹中显示”定位原文件。外部打开暂不保证跳到指定页或段落。

正文无法解析时，结果会显示原因，如需要 OCR、密码保护、编码问题或超出限制。点击侧栏索引状态，可分页查看问题文档的名称、完整路径和原因。修复原文件或权限后，点击“重试此文档”；预览中也有相同入口。重试只重新解析选中文档，保留收藏；期间旧正文会撤下并显示“内容待更新”。暂停时先排队，继续索引后处理，退出重启也会保留待处理状态。“重新检查全部”仍可复查全库，不会丢弃暂停中或扫描途中提交的新请求。

## 范围与本地数据

“索引与排除 → 排除子目录”填写相对路径，例如 `archive/private`。排除规则优先于重叠的包含规则。每条规则旁的“恢复索引”可直接撤销这一条排除，随后重新发现该目录；其他范围中的排除规则仍然生效。目录恢复后会重建派生数据，之前因排除而删除的收藏不会自动恢复。

自动磁盘不能从此处移除，可排除其子目录。清除全部本地数据会删除索引、收藏、排除和设置，并暂停自动索引。点击“继续索引”会从自动发现的磁盘重新建立索引。原文件不会修改。清理会压缩数据库，但不承诺 SSD 上的取证级安全擦除。

默认目录：Windows 为 `%LOCALAPPDATA%\Shiwen`，macOS 为 `~/Library/Application Support/Shiwen`，Linux 为 `$XDG_DATA_HOME/Shiwen`（通常 `~/.local/share/Shiwen`）。设置页显示真实路径。开发时可使用 `--data-dir` 指定独立目录。

## 检查更新与下载

打开 **设置 → 软件更新 → 检查更新**，查看新版本和说明。选择安装包（Linux 可选 DEB 与免安装 tar.gz），点击 **下载安装包**。支持查看下载进度和取消；下载完成前会核对大小与 SHA-256，不完整或校验失败的包会删除。

完成后点击 **打开下载文件夹**。安装包保存在系统下载目录中新建的 `Shiwen-…` 子目录，不覆盖之前的下载。退出拾文后安装 DEB，或解压替换应用；保留原数据目录即可保留索引和设置。当前版本负责下载，不自动安装或重启。

仅手动更新操作连接 GitHub；启动、索引、搜索和打开设置均不会自动检查网络。文档、文件路径和索引内容不会上传。测试版可检查后续测试版或正式版；正式版忽略预发布版本；不会提供降级包。网络失败时可重试，或点击 **查看发布页** 使用浏览器下载。

## 常见问题

- **搜不到：** 检查目录、文件类型、索引状态。扫描 PDF 需在外部完成 OCR 后重新索引。
- **更新文件后暂时没有正文：** 检测到更新时先撤下旧文本，待新版解析成功后加入；不会把旧正文冒充当前内容。
- **移动后收藏失效：** 当前未实现跨路径身份关联和收藏迁移，请在新位置重新收藏。
- **Windows 无法启动窗口：** 检查 WebView2 是否安装。应用不回退到 Internet Explorer。
- **macOS 阻止启动：** 按系统提供的下载应用批准流程处理，无需关闭全局安全功能。
- **数据库损坏：** 退出应用，将数据目录移到其他位置保留，再启动即可自动重建。自动修复后续实现。旧数据库包含原文，不要公开上传。


## 关闭应用

点击标题栏 × 会关闭桌面窗口，并请求取消索引和下载；未完成文档在下次启动后继续。没有“关闭后缩到托盘”的行为。beta.8 修复了 Linux 窗口销毁后界面回调一直等待的退出竞态。若旧版本已卡住，可在系统监视器中结束对应的拾文进程一次，再打开升级后的应用。网络操作的退出清理仍可能等待当前请求超时。
