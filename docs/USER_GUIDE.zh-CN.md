# 使用说明

[English](USER_GUIDE.en.md) · [返回首页](../README.zh-CN.md)

## 添加资料

点击“添加文件夹”。拾文会读取其中的 PDF、`.md`、`.markdown`、`.docx`。父子目录重复添加不会产生重复结果。隐藏目录、常见依赖目录、符号链接及应用自己的数据目录会被跳过；不能选择整盘或包含拾文数据目录的上级目录。

请选择已经存储在本机的文件夹。应用不会主动下载云盘占位文件。测试版不承诺支持网络共享与移动磁盘的完整生命周期。

索引在后台进行。点击侧栏底部的状态，可查看处理数量、暂停、继续或重新检查。保存文件后会等待约一秒，避免读取写入中的文件；系统通知遗漏时，定期核对可能需要约 30 秒才能发现变化。

## 搜索规则

| 输入 | 含义 |
| --- | --- |
| `部署` | 在名称或正文中查找这个双字片段 |
| `预算 审批` | 同一份文档同时包含两个条件 |
| `"offline deployment"` | 连续短语，忽略英文大小写和连续空白差异 |
| `C++` | 作为普通文字匹配，不执行正则表达式 |

每个搜索词至少两个规范化字符，最多 12 个词、总计 256 个输入字符。英文大小写、全角兼容字符会规范化。当前不做简繁转换、OCR、拼写纠正、同义词和语义搜索。

类型按钮、文件夹与收藏范围可以组合。“最近修改”使用原文件的修改时间。清空关键词后，显示当前范围内最近修改的文档，已有筛选继续生效。

每次最多显示 50 项，可点击“加载更多”。未检查全部候选前，不显示伪造的精确总数。

## 预览和打开

单击结果查看提取文本，通过上下箭头切换命中的页或文本块。位置对应 PDF 物理页、Markdown 源文件起始行、DOCX 段落序号。此版本不渲染原始 PDF 页面，也不还原 Word 排版。

“打开原文件”、双击结果或在结果列表按 Enter，均调用系统默认应用。“在文件夹中显示”定位原文件。外部打开暂不保证跳到指定页或段落。

正文无法解析时，结果会显示原因，如需要 OCR、密码保护、编码问题或超出限制。当前“重新检查与重试”会复查全部范围，单文件重试后续提供。

## 范围与本地数据

“管理文件夹 → 排除子目录”填写相对路径，例如 `archive/private`。排除规则优先于重叠的包含规则。当前不提供单条排除规则的删除按钮；可移除该范围后重新添加以重置规则。

移除范围会删除其派生检索数据；仍被其他范围包含的文件继续保留。清除全部本地数据会删除索引、收藏、范围和设置。两者都不会修改原文件。清理会压缩数据库，但不承诺 SSD 上的取证级安全擦除。

默认目录：Windows 为 `%LOCALAPPDATA%\Shiwen`，macOS 为 `~/Library/Application Support/Shiwen`，Linux 为 `$XDG_DATA_HOME/Shiwen`（通常 `~/.local/share/Shiwen`）。设置页显示真实路径。开发时可使用 `--data-dir` 指定独立目录。

## 常见问题

- **搜不到：** 检查目录、文件类型、索引状态。扫描 PDF 需在外部完成 OCR 后重新索引。
- **更新文件后暂时没有正文：** 检测到更新时先撤下旧文本，待新版解析成功后加入；不会把旧正文冒充当前内容。
- **移动后收藏失效：** 当前未实现跨路径身份关联和收藏迁移，请在新位置重新收藏。
- **Windows 无法启动窗口：** 检查 WebView2 是否安装。应用不回退到 Internet Explorer。
- **macOS 阻止启动：** 按系统提供的下载应用批准流程处理，无需关闭全局安全功能。
- **数据库损坏：** 退出应用，将数据目录移到其他位置保留，再启动并重新添加范围。自动修复后续实现。旧数据库包含原文，不要公开上传。
