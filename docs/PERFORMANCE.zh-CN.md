## 本机环境与方法

Ubuntu 22.04 x64、Linux 6.8、Python 3.10、Intel Core i9-14900HX（32 个逻辑核）、约 15.32 GiB 内存；后台有开发工具运行。并非原定 4 核 / 8 GB 参考机器。未清空系统缓存；重新打开 SQLite 不等于冷缓存测试。

新语料共 **10,000 份文档：4,000 份三页文字 PDF、4,000 份 Markdown、2,000 份包含段落与表格的完整 DOCX 包**。总文件大小 119,439,763 字节（113.91 MiB）。均为结果可验证的中英文合成文本，不代表私人真实文档或复杂排版。使用生产自动发现与独立子进程解析器，查询均核对预期结果数量。

完整首建基线在最终查询优化前记录，原始版本保留为 `0.1.0b9`；最终查询及桌面报告为 `0.1.0`，生产代码来自 `9c3bb7a`，测量修正在 `e848222`。原始报告保留测量阶段，不把旧数据改标成最终版。

## 最终版正文查询

100 条查询，每组 25 条，每次取最多 50 个结果；P95 使用最近秩。复用已有万文档索引，未重新建库或清空缓存。大量相似数字标识符会产生较多二元字符候选，因此唯一记录查询也可能较慢。

| 查询组 | 中位数 | P95 |
| --- | ---: | ---: |
| 主题词 | 265.11 ms | 301.13 ms |
| 唯一记录 | 747.24 ms | 761.90 ms |
| 短语 / AND 条件 | 422.69 ms | 545.02 ms |
| 不存在的词 | 0.39 ms | 0.46 ms |

先核对候选文字，再做文件系统权限检查；大块正文结构仅为实际命中项读取。所有返回结果仍检查范围与可访问性。优化减少误候选成本，但不承诺所有查询瞬时完成。

## 真实本机名称与百万合成名称

新建独立的仅名称索引，在 **305.15 秒发现 739,334 个文件 / 文件夹**，此次不解析正文。公开报告仅含汇总数字，不包含私人路径或数据库。增加查询索引后，空查询中位数为 18.67 ms（此前 464.16），单字符为 69.23 ms（此前 559.09），常见文件名为 38.31 ms，扩展名为 40.82 ms。每项 10 次，未控制冷热缓存；数据库 + WAL 为 510.59 MiB。

另一个 **1,000,000 条合成名称索引**写入耗时 73.25 秒，优化后占 533.74 MiB。这是使用虚拟路径的 SQL 工作负载，**不包含真实磁盘遍历和逐项权限检查**。每项 5 次：

| 查询 | 中位数 | P95 |
| --- | ---: | ---: |
| 空查询 | 0.97 ms | 1.45 ms |
| 大量匹配 `File` | 2,689.38 ms | 2,700.58 ms |
| 唯一编号 `0999999` | 149.35 ms | 154.41 ms |
| 单字符 `f` | 0.99 ms | 1.21 ms |
| 不存在的词 | 0.10 ms | 0.27 ms |

大量匹配仍约需 2.7 秒，不能据此宣称达到 Everything / NTFS MFT 的速度。自动核对采用常规遍历，间隔约 30 秒，另加扫描耗时。

## 真实桌面

原生桌面验收使用生产应用，检查自动发现、中文正文检索、高亮预览、收藏、PDF / Markdown / DOCX 筛选、设置、中英文与深浅主题，以及自绘最小化 / 最大化 / 还原 / 关闭、拖动和缩放。测试使用独立合成索引，不改动用户文档库。

本机万文档已有索引的首批结果 **0.91 秒**出现，请求关闭后 **0.28 秒**退出。完整应用及子进程 RSS 在交互前为 **527.72 MiB**，交互后空闲为 **573.79 MiB**，全程采样峰值为 **600.02 MiB**。交互后十秒空闲采样扣除采样线程后使用 **单核 25.2% CPU**。环境无可访问 GPU，启用了软件渲染回退；空闲 CPU 仍明显，是后续优化项。

RSS 汇总含 Python、存在时的解析子进程和 WebView；共享页可能重复计算，短暂峰值可能遗漏。十秒样本不代表续航或长期空闲状态。已有索引测试中标为 `indexing` 的阶段包含启动核对，不是重新解析整个语料。Linux 仅在没有可访问 GPU 时默认禁用 WebKit 合成，并尊重用户显式环境变量。

以下另列三平台 CI 测量。机器、语料规模、渲染环境不同，不构成受控的操作系统性能比较。

## 延期验收与限制

严格系统冷缓存、4 核 / 8 GB 参考机、复杂真实语料、长时间功耗，以及 Windows / macOS / Linux 实体机完整原生对话框、权限与恢复人工验收仍未验证。CI 自动检查不能替代这些人工检查。安装包仍无可信发布者签名（macOS 可能有临时签名）；OCR、NTFS MFT / USN、损坏数据库自动修复、跨路径重命名保留收藏尚未实现。详见[路线图](ROADMAP.md)。
